    Surface Options¶

    Surface options describe how an entity renders (colour, roughness, metalness, emission, textures). Genesis surfaces cannot be created before gs.init(), so SurfaceOptions records the specification in the config and creates the Genesis surface when the scene is built. Set one as an entity's surface field.

    from eden.options.surfaces import PlasticSurfaceOptions

    Surface appearance options (plastic, metal, glass, ...).

    Attributes¶

    SurfaceLike module-attribute ¶

    SurfaceLike: TypeAlias = SurfaceOptions | Surface

    Either an Eden :class:SurfaceOptions (deferred) or a built Genesis :class:Surface.

    Classes¶

    SurfaceOptions ¶

    SurfaceOptions(**data)

    Bases: ConfigurableOptions

    Deferred, serializable description of a Genesis surface.

    Genesis surfaces (gs.surfaces.*) cannot be instantiated before gs.init() (they reference gs.EPS internally), so they cannot be embedded directly in an EdenConfig that is constructed at import time. SurfaceOptions captures the surface specification as plain config data and materializes the real Genesis surface lazily via :meth:to_genesis_surface at build time.

    Subclasses set _genesis_surface_cls to the corresponding gs.surfaces.* class; every non-None field (declared or extra) is forwarded to it.

    PARAMETER DESCRIPTION
    color

    Surface color. Shortcut for the primary texture with a single color (RGB or RGBA).

    TYPE: array - like[float] | None

    opacity

    Opacity of the surface in [0, 1].

    TYPE: float | None

    roughness

    Roughness of the surface in [0, 1].

    TYPE: float | None

    metallic

    Metalness of the surface in [0, 1].

    TYPE: float | None

    emissive

    Emissive color of the surface.

    TYPE: array - like[float] | None

    ior

    Index of refraction.

    TYPE: float | None

    vis_mode

    How the entity should be visualized ('visual', 'collision', 'particle', 'sdf', 'recon').

    TYPE: str | None

    double_sided

    Whether to render both sides of the surface.

    TYPE: bool | None

    smooth

    Whether to smooth face normals by interpolating vertex normals. Default True.

    TYPE: bool

    def to_genesis_surface(self) -> Surface:
    """Materialize the Genesis surface. Must be called after ``gs.init()``."""
    # Forward every set value (declared fields + dynamic extras), dropping unset
    # ``None`` shortcuts so the Genesis surface keeps its own defaults.
    kwargs = {key: value for key, value in self.dict().items() if value is not None}
    return self._genesis_surface_cls(**kwargs)

    def resolve_surface(surface: SurfaceLike | None) -> Surface | None:
    """Resolve a surface spec to a Genesis surface, building deferred ``SurfaceOptions``."""
    if isinstance(surface, SurfaceOptions):
        return surface.to_genesis_surface()
    return surface
