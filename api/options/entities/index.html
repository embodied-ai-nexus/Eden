    Entity Options¶

    Entity options describe one thing in the scene: a mesh or URDF/MJCF asset (EntityOptions, RobotOptions), a primitive shape, a terrain, a bank of per-env variants (GroupedEntityOptions) or a multi-entity rig (CompositeEntityOptions). SceneOptions holds them as named children; each name becomes the key of env.entities. The entities guide explains pose frames, DOF fields and contact parameters; the scenes guide covers scenes and terrain.

    from eden.options.entities import BoxOptions, SceneOptions

scene_options = SceneOptions(box=BoxOptions(size=(0.1, 0.1, 0.1), default_root_pos=(0.0, 0.0, 0.6)))

    Quaternion fields (default_root_quat, ...) are wxyz.

    def named_entities(self) -> dict[str, BaseEntityOptions]:
    """Every entity the scene will build, keyed by final entity name (composites expanded)."""
    out: dict[str, BaseEntityOptions] = {}
    for key, entity in (self.__pydantic_extra__ or {}).items():
        if key.startswith("_option_"):
            continue
        if isinstance(entity, CompositeEntityOptions):
            out.update(entity.entity_options())
        elif isinstance(entity, BaseEntityOptions):
            out[key] = entity
    return out

    def remove_entity(self, name: str) -> None:
    """Remove the entity placed under scene key ``name``, together with its own attachment.

    The supported way for a task variant to drop an entity (see
    ``eden/tasks/robosuite/variants.py::drop_object``). Only an entity added by
    name (an extra) is removable; one declared as a field of a ``SceneOptions`` subclass
    (``DroidSceneOptions.robot``) is part of that scene class. An ``attachments_dict`` entry
    that welds the removed entity onto a parent goes with it. An entity that *other* entities
    are welded onto cannot be removed — remove the children first. Nothing else that names
    the entity is touched — manager terms, cameras, sensors — so update those too, otherwise
    they fail to resolve the entity at build time.

    Parameters
    ----------
    name : str
        Scene key of the entity. A composite is removed whole, under its placement key; one of
        its bodies cannot be removed on its own.

    Raises
    ------
    RuntimeError
        If the scene options are locked (checked before anything else).
    KeyError
        If the scene has no entity ``name`` (the message lists the removable entities), or
        ``name`` cannot be removed: a declared field, or a body of a composite (the message
        says which).
    ValueError
        If another entity is attached to the one being removed.
    """
    try:
        entity = self._removable_child(name, noun="entity")
    except KeyError as err:
        # The generic "not found" would be wrong for an entity that exists but is not an extra.
        reason = self._unremovable_entity_reason(name)
        if reason is None:
            raise
        raise KeyError(reason) from err
    # A composite produces several scene entities (arm + gripper); all of them go with it.
    removed_names = set(entity.entity_names) if isinstance(entity, CompositeEntityOptions) else {name}
    dependents = sorted(
        child
        for child, spec in self.attachments_dict.items()
        if spec[0] in removed_names and child not in removed_names
    )
    if dependents:
        raise ValueError(
            f"Cannot remove entity '{name}': {dependents} are attached to it via attachments_dict. "
            f"Remove those entities first."
        )

    self._remove_named_child(name, noun="entity")
    # Rebuilt, not edited in place: a shallow model_copy() shares the dict with its source scene,
    # which would silently lose its own welds.
    self.attachments_dict = {
        child: spec for child, spec in self.attachments_dict.items() if child not in removed_names
    }

    PARAMETER DESCRIPTION

    Default root position.

    TYPE: array - like[float, float, float]

    Default root orientation as quaternion in (w, x, y, z).

    TYPE: array - like[float, float, float, float]

    Whether the entity base is fixed.

    TYPE: bool

    is_articulated

    Whether the entity has articulation.

    TYPE: bool

    is_actuated

    Whether the entity is actuated.

    TYPE: bool

    material

    Material used for the entity.

    TYPE: MaterialLike | None

    surface

    Surface appearance used for the entity. Prefer an Eden :class:SurfaceOptions (e.g. PlasticSurfaceOptions(color=(1.0, 0.0, 0.0))) in configs constructed before gs.init(); a raw gs.surfaces.* instance is also accepted.

    TYPE: SurfaceOptions | Surface | None

    color

    Convenience shortcut to color the entity. When set (and surface is not), a plastic surface with this color (RGB or RGBA) is created at build time.

    TYPE: array - like[float] | None

    visualize_contact

    Whether to visualize contacts involving this entity.

    TYPE: bool

    vis_mode

    Visualization mode for the entity.

    TYPE: VisMode

    visualization

    Whether to visualize the entity.

    TYPE: bool

    collision

    Whether this entity participates in collision checking.

    TYPE: bool

    contype

    32-bit collision-filter bitmask. Two geoms can collide only if the contype of one and the conaffinity of the other share a set bit. Defaults to 0xFFFF.

    TYPE: int

    conaffinity

    32-bit collision-filter bitmask. See contype. Defaults to 0xFFFF.

    TYPE: int

    collision_link_patterns

    Regex/glob patterns matched against link names. When set, only geoms on matching links keep collision; geoms on all other links are disabled (contype = conaffinity = 0). Use to restrict an entity's collisions to specific parts — e.g. a parallel-jaw gripper's fingertip pads ([".*pad"]) so objects are grasped at the pads instead of wedging against the inner linkage. Applied before the scene is built (Genesis bakes the collision-pair list at build time). None keeps the morph's default per-geom collision.

    TYPE: list of str

    collision_friction

    Friction coefficient applied to the geoms kept by collision_link_patterns (e.g. high pad friction for stable grasps).

    TYPE: float

    batch_fixed_verts

    Whether fixed-geometry vertices are batched for per-env transforms.

    TYPE: bool

    is_support_enabled

    Whether support-point computation is enabled.

    TYPE: bool

    support_sample_method

    The method to sample the support points. Defaults to "uniform".

    TYPE: Literal['uniform', 'grid']

    support_minimum_clearance

    The minimum clearance to be considered for support points. Defaults to 0.05.

    TYPE: float

    support_shrink

    The shrink factor to be applied to the support points. Defaults to 0.1.

    TYPE: float

    support_num_sample_points

    The number of support points to sample per square meter of polygon. Defaults to 300.

    TYPE: int

    support_grid_size

    The size of the grid to sample the support points when support_sample_method is "grid". Defaults to 0.01.

    TYPE: float

    support_links_name

    Exact link names (URDF link names / MJCF body names) whose geometry should be considered when extracting support surfaces. Empty (default) means all links contribute. Use this on multi-link assets (e.g. the Riverway franka station) to restrict placement targets to a specific surface like ["station_table_top"] so events don't spawn objects onto auxiliary cart / gantry tops.

    TYPE: list[str]

    dofs_name

    Controllable DOF names.

    TYPE: list[str]

    dofs_spec

    Class-level default actuator specification map for DOFs.

    TYPE: ClassVar[dict[str, type[ActuatorSpecOptions]]]

    default_dofs_pos

    Default DOF positions.

    TYPE: dict[str, float]

    default_dofs_vel

    Default DOF velocities.

    TYPE: dict[str, float]

    default_dofs_kp

    Default DOF position gains.

    TYPE: dict[str, float]

    default_dofs_kd

    Default DOF velocity gains.

    TYPE: dict[str, float]

    default_dofs_stiffness

    Default DOF stiffness values.

    TYPE: dict[str, float]

    default_dofs_damping

    Default DOF damping values.

    TYPE: dict[str, float]

    default_dofs_armature

    Default DOF armature values.

    TYPE: dict[str, float]

    default_dofs_frictionloss

    Default DOF dry-friction (stiction) torques. Values below the drive torque leave actuation unaffected while absorbing sub-threshold oscillation (contact chatter).

    TYPE: dict[str, float]

    default_dofs_spring_ref

    Re-anchor a DOF's passive spring (default_dofs_stiffness / the file's joint stiffness) at this reference position instead of the initial qpos. Genesis ignores MJCF springref and anchors joint springs at qpos0, which silently drops any preload (e.g. the Robotiq 2F85's spring links). Implemented at build by moving the spring to a position servo: sim stiffness is zeroed and the DOF gets kp = stiffness with the reference as its (persistent) position target — do not also drive these DOFs from an action term.

    TYPE: dict[str, float]

    default_dofs_pos_limits

    Hard DOF position limits.

    TYPE: dict[str, array - like[float, float]]

    soft_dofs_pos_limits

    Soft DOF position limits.

    TYPE: dict[str, array - like[float, float]]

    default_dofs_force_limits

    Default DOF force limits.

    TYPE: dict[str, float]

    default_equalities_sol_params

    Constraint solver parameters (timeconst, dampratio, dmin, dmax, width, mid, power) applied to all of the entity's equality constraints (loop closures, joint couplings) at build. Note genesis clamps timeconst to 2*substep_dt, so a stiff value needs a matching sim_dt/sim_substeps.

    TYPE: SolParamsType | None

    Per-env variants¶

    GroupedEntityOptions ¶

    GroupedEntityOptions(**data)

    Bases: BaseEntityOptions

    Grouped entity used for heterogeneous batching.

    Supports both non-articulated entities (Mesh, Primitive) and articulated entities (URDF) that share the same joint structure (same number of links, joints, and DOFs).

    Each variant contributes its morph (file or shape, mesh processing, its own default_root_pos / default_root_quat), and may hold its own value for some of the group's fields. A variant holds a value when it differs from the field's default, whether passed in or its catalog class's default.

    • Per variant (variant_values(), variant_materials): the geom fields (default_geoms_friction*, default_geoms_sol_params), the per-DOF ones (default_dofs_* and soft_dofs_pos_limits) and the material's rho / friction*. Each env takes its variant's own value, else the group's. Variants that differ in a simulated DOF field (gains, stiffness, damping, armature, frictionloss, force limits) need EnvOptions(batch_dofs_info=True). A per-variant rho rescales each env's mass after the build, so it needs a mesh or primitive variant, whose mass Genesis computes from its density.
    • Shared (shared_dof_fields(), shared_dofs_spec): dofs_name and default_dofs_spring_ref, the group's own or, when it sets none, that of the first variant that sets one; a variant's own different value is refused. So is a variant class's dofs_spec that differs from another's.
    • Group only: every other field (surface, color, is_fixed_base, the support and collision mask fields, the other material fields): a variant's own different value is refused.

    A variant overrides the group's own value for a per-variant field only with a value other than its class's default: one equal to the class default is read as inherited and refused, as the group's value would silently skip it. The group's value is also refused when every variant overrides it, as it would apply to none of them. check_variants runs these checks; the entity runs it again before the build.

    """The named sub-entities keyed by name (uncopied), and where a name collision is caught.

    Framework-owned: subclasses implement :meth:`entity_parts` instead, so this check cannot
    be bypassed by method dispatch.

    Two bodies under one name collapse to a single entry, leaving the composite one body
    short with nothing downstream noticing: :attr:`entity_names`, :meth:`expand` and the
    cross-composite check in :meth:`SceneOptions.model_post_init` all read *this* dict, so
    none of them can see what has already been overwritten. Checked here, on every call, not
    only at construction (:meth:`model_post_init` calls this) — these Options do not
    ``validate_assignment``, so a ``*_name`` reassigned after construction would slip past a
    construction-time-only guard.
    """
    parts = self.entity_parts()
    names = [name for name, _ in parts]
    collisions = sorted({name for name in names if names.count(name) > 1})
    if collisions:
        raise ValueError(
            f"{type(self).__name__} gives two bodies the same name {collisions}, but a "
            f"composite's entity names ARE the scene's entity names, so each body needs its "
            f"own; got {names}. Set the colliding '*_name' field(s) to something distinct."
        )
    return dict(parts)

    def expand(self) -> tuple[dict[str, "BaseEntityOptions"], dict[str, tuple[str, str]]]:
    """Return ``(named_entities, attachments)`` for the scene build loop.

    The sub-entity Options are deep-copied so one composite instance can be placed in
    several scenes (or reused from the registry) without the scenes aliasing — and
    mutating — the same Options. (``copy.deepcopy`` — not pydantic ``model_copy`` —
    because genesis' Options define ``__deepcopy__(self, memo)``.)
