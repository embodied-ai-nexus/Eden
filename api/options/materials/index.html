    Material Options¶

    A material selects the solver that simulates an entity and that solver's physical parameters: rigid (and kinematic) bodies, MPM, SPH, PBD and FEM deformables, and the Eden-hosted Mochi solver. Set it as an entity's material field. The physics guide explains each solver.

    from eden.options.materials import RigidMaterialOptions

RigidMaterialOptions(gravity_compensation=1.0)  # gravity compensation is a material field

    A Mochi scene is all-Mochi: every entity, the ground plane included, takes a Mochi*MaterialOptions.

    Material options for rigid, MPM, SPH, FEM, PBD, and Mochi entities.

    def to_genesis_material(self):
    cls = self._genesis_material_cls
    if cls is None:
        raise NotImplementedError(f"{type(self).__name__} does not implement to_genesis_material()")
    # Drop None-valued fields so Genesis applies its own (often lazily-resolved)
    # defaults rather than seeing an explicit ``None``. Several Genesis materials
    # reject an explicit ``sampler=None`` even though it is their ``__init__``
    # default (e.g. ``gs.materials.MPM.Elastic``), so forwarding None would make
    # ``MPMElasticMaterialOptions()`` unusable.
    return cls(**{k: v for k, v in self.dict().items() if v is not None})

    RigidMaterialOptions ¶

    RigidMaterialOptions(**data)

    Bases: MaterialOptions

    Options for Genesis rigid materials.

    PARAMETER DESCRIPTION
    rho

    The density of the material used to compute mass. Default is 200.0.

    TYPE: float

    friction

    Friction coefficient within the rigid solver. If None, a default of 1.0 may be used or parsed from file.

    TYPE: float

    friction_torsional

    Torsional friction coefficient: how strongly a contact resists relative spin about its normal. Expressed in meters — it is the effective contact-patch radius, and it bounds the resisting torque at friction_torsional * normal_force. Requires EnvOptions.enable_torsional_friction (Eden raises at build if the switch is off) and costs one extra constraint axis per contact. If None, parsed from the asset when available (MJCF friction[1], only for geoms declaring condim >= 4), otherwise genesis' 0.005. Default is None.

    TYPE: float

    friction_rolling

    Rolling friction coefficient: how strongly a contact resists rolling about its two tangent axes. In meters like friction_torsional. Requires EnvOptions.enable_rolling_friction (which itself requires enable_torsional_friction) and costs two extra constraint axes per contact. If None, parsed from the asset when available (MJCF friction[2], only for geoms declaring condim >= 6), otherwise genesis' 0.0001. Default is None.

    TYPE: float

    needs_coup

    Whether the material participates in coupling with other solvers. Default is True.

    TYPE: bool

    coup_friction

    Friction used during coupling. Must be non-negative. Default is 0.1.

    TYPE: float

    coup_softness

    Softness of coupling interaction. Must be non-negative. Default is 0.002.

    TYPE: float

    coup_restitution

    Restitution coefficient in collision coupling. Should be between 0 and 1. Default is 0.0.

    TYPE: float

    sdf_cell_size

    Cell size in SDF grid in meters. Defines grid resolution. Default is 0.005.

    TYPE: float

    sdf_min_res

    Minimum resolution of the SDF grid. Must be at least 16. Default is 32.

    TYPE: int

    sdf_max_res

    Maximum resolution of the SDF grid. Must be >= sdf_min_res. Default is 128.

    TYPE: int

    gravity_compensation

    Compensation factor for gravity. 1.0 cancels gravity. Default is 0.

    TYPE: float

    coup_type

    Coupling mode for this entity. Only used by the IPC coupler. Requires needs_coup=True. If None, auto-selected based on entity type: 'external_articulation' for fixed-base articulated robots, 'two_way_soft_constraint' for floating-base robots, and 'ipc_only' for non-articulated objects. Valid values: - 'two_way_soft_constraint': Two-way soft coupling. - 'external_articulation': Joint-level coupling for articulated bodies. Joint positions will be coupled at the DOF level. - 'ipc_only': IPC controls entity, transforms copied to Genesis (one-way). Only supported by rigid non-articulated objects. Default is None.

    TYPE: str or None

    coup_links

    Link names to include in coupling. When set, only the named links participate in coupling; other links are excluded. Only supported with needs_coup=True and two_way_soft_constraint type in IPC. Default is None.

    TYPE: list of str or None

    enable_coup_collision

    Whether coupler collision is enabled for this entity's links. Only used by the IPC coupler. Unlike needs_coup=False (which removes the entity from the coupler entirely), setting this to False keeps the entity in the coupler for coupling forces but disables contact response. Default is True.

    TYPE: bool

    coup_collision_links

    Link names whose geoms participate in coupler collision. Only used by the IPC coupler. Only effective when enable_coup_collision=True. If None, all coupled links have collision. When set, only the named links get coupler collision; other links are marked no-collision. Default is None.

    TYPE: list of str or None

    contact_resistance

    IPC coupling contact resistance/stiffness override for this entity. None means use IPCCouplerOptions.contact_resistance. Default is None.

    TYPE: float or None

    MochiShellMaterialOptions ¶

    MochiShellMaterialOptions(**data)

    Bases: MochiMaterialOptions

    Options for Mochi thin shells / cloth (eden.engine.solvers.mochi.materials.Shell).

    The surface triangles of a Mesh (or primitive) morph become a Saint Venant-Kirchhoff membrane plus a Koiter-type bending term, both thickness-integrated from E, nu, rho and thickness unless overridden. Shells act as colliders through spheres of collider_radius at their vertices, which only other point-cloud bodies (cloths, rods) and — with self_contact — the shell itself feel; rigid bodies and solids touch the shell through its own contact samples.     MochiRodMaterialOptions(**data)

    Bases: MochiMaterialOptions

    Options for Mochi discrete elastic rods (eden.engine.solvers.mochi.materials.Rod).

    A Kirchhoff rod (stretch, bend, twist; no shear) on the polyline of a :class:~eden.options.entities.RodOptions morph — the only morph this material accepts. The five stiffness / inertia quantities derive from E, nu, rho and the rod radius unless given explicitly. Clamp a rod by fixing its first two nodes. Rods collide through samples on their centerline and act as colliders through node spheres of the rod radius, which only other point-cloud bodies (and the rod itself under self_contact) feel.
