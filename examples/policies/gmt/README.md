# GMT: General Motion Tracking

This is an inference code of GMT based on the [official implementation](https://github.com/zixuan417/humanoid-general-motion-tracking) under [LICENSE](https://github.com/zixuan417/humanoid-general-motion-tracking/blob/master/LICENSE).

## Policy Inference

```
python main.py --motion-file motions/crouchwalk_stand.pkl
```
