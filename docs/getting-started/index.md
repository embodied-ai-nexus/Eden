# Get started

New to Eden? These pages take you from an empty machine to a policy you trained and a task you wrote yourself.
Read them in order the first time; each one ends by pointing at the next.

<div class="eden-grid" markdown>

<div class="eden-card" markdown>

### [Installation](installation.md)

Install `eden-world` from PyPI or from a clone with uv, choose optional extras, and check that it works.

</div>

<div class="eden-card" markdown>

### [Quick start](quickstart.md)

Train a policy with `eden train`, watch it with `eden inference`, then export it and try it against MuJoCo.

Where robot, object and dataset files are downloaded to, how to move the cache, and how to run offline.
